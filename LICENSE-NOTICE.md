# Historical license notice and release gate

The historical `Quadstream00/README` in this repository states that the old Quadstream code is released under the **GNU Lesser General Public License**, without specifying a version. Historical dependencies and bundled scripts also carry their own notices, which must be preserved.

This modernization does not change the licensing of those historical files. A precise modern root SPDX license, complete license text, ownership/provenance review and any required third-party NOTICE files are **pending**, not implicitly granted by this document.

The new npm package is marked `private: true` and must not be published until the maintainers approve and document the distribution terms. This is a release gate, not a statement that users lack rights already provided by the historical code's applicable license.
